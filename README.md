# DomainGuard

A firewall with domain rules, delayed changes, and temporary pauses. See [features and build instructions](README-DomainGuard.md) or [download the latest APK](https://github.com/phooBarred/DomainGuard-downloads/releases/latest/download/DomainGuard.apk).

DomainGuard is a modified GPLv3 build of HeartGuard, which derives from NetGuard. The original upstream documentation follows.

# HeartGuard

*HeartGuard* is a self-control utility that is based on [NetGuard](https://github.com/M66B/NetGuard/tree/master)

This app is meant to be used together with [Plucky](pluckyfilter.com) and Andoff
HeartGuard controls internet access per app based on rules with a configurable self-control delay.

Please read the user guide [here](https://github.com/hoodedpaladin/HeartGuard/wiki/User-Guide)
